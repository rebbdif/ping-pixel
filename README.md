# Ping Pixel

Pixel table tennis in black-and-white handheld style. Tilted pseudo-3D table, five rivals (Xenia, Egor, Leonid the octopus, Bolt the robot, Zorp the alien), three rounds, a prize screen at the end.

Run locally:

    npm start   # http://localhost:3000

Controls: mouse / drag / arrows to move, click / Space / A to serve, A right before contact to smash.
