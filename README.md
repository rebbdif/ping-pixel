# Ping Pixel

Pixel table tennis in black-and-white handheld style. Tilted pseudo-3D table, five rivals (Xenia, Egor, Leonid the octopus, Bolt the robot, Zorp the alien), one match to 7, a prize screen at the end.

Play online: https://rebbdif.github.io/ping-pixel/

Run locally:

    npm start   # http://localhost:3000

Controls: on a computer, ← → arrows and Space (M toggles sound). On a phone, drag your finger to move and tap to serve or smash.
